**Sales Performance Dashboard**
This dashboard provides a comprehensive analysis of sales performance for the Coffee Shop chain, allowing stakeholders to track revenue trends, transaction volume, and product-level insights.

**Dashboard Overview**
The dashboard is built in Power BI and focuses on key business performance indicators to help store managers make data-driven decisions.

**Key Features**
Revenue Insights: A clear overview of total revenue generated across various store locations.

AOV Tracking: Monitoring the Average Order Value to understand customer spending behavior.

Transaction Volume: Tracking the number of transactions to measure store activity.

Interactive Filtering: Users can drill down into the data using slicers for Time Buckets, Product Categories, and specific months.

How to Access
Download: Click on the CoffeeShop_Sales_Dashboard.pbix file in this folder to download it.

Open: Open the file using Power BI Desktop.

Interact: Use the slicers at the top of the report to filter the dashboard by date, product, or location.
